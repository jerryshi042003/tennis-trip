# Tennis Trip

Who to contact and what to send for Jerry's Philippines and Japan tennis trip (Nov–Dec 2026), plus flights, stays and tournaments. Installable as a phone app.

Build: `python3 src/import_outreach.py && python3 src/build.py` (reads the outreach trackers in the parent `projects/` folder, writes `public/`).
Deploy: `vercel --prod --yes --scope jerryshi042003s-projects`.
